# Vértice Motors — landing page

Página estática em português para uma concessionária conceito. Não requer instalação nem etapa de build.

## Prévia
Abra index.html em um navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie o conteúdo desta pasta: index.html, README.md e .nojekyll.
2. Abra Settings → Pages no repositório.
3. Em Build and deployment, selecione Deploy from a branch, escolha a branch main e a pasta / (root), e salve.
4. O endereço publicado aparecerá na seção Pages depois que o GitHub concluir a publicação.

Antes de usar comercialmente, substitua o nome, os modelos, as ilustrações e os textos pelos dados reais da concessionária. O catálogo desta página é ilustrativo.
